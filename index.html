GitHub Pages 用テンプレート

卒業研究プログラム公開ページ

卒業研究で使用する実験プログラム，尺度回答ページ，関連資料をまとめて公開するためのトップページです。 GitHub リポジトリ sotsu-ron にこの index.html を配置すれば，GitHub Pages の公開ページとして利用できます。

公開中のプログラムを見る GitHub Pages の設定方法

※ 上の2つのボタンは別ページに移動するボタンではなく，このページ内の該当セクションまでスクロールするボタンです。

このページについて

このページは，心理学系の卒業研究で使用するプログラムや実験資料を整理して公開することを目的としています。 研究参加者向けの実験ページと，研究者向けの説明資料を分けて掲載できる構成にしています。

運用上の注意 参加者が実際にアクセスするページを公開する場合は，個人情報，教示内容，ランダム割り当て情報，内部資料が同じ公開領域に含まれないように注意してください。

公開中のプログラム

下のカードに，GitHub Pages 上で公開する各プログラムへのリンクを追加してください。 現在はサンプルとして，PANAS 回答ページの枠を入れています。

尺度回答 PANAS 単一HTML

PANAS 回答ページ

日本語版PANAS 16項目に回答するためのページです。参加者ID入力，事前・事後選択，PA/NA得点計算，CSVダウンロードに対応しています。

公開URL：
./panas_pre_post/

GitHub Pages上の想定URL：
https://USERNAME.github.io/sotsu-ron/panas_pre_post/

自伝的記憶想起課題

手がかり語を提示し，具体的な自伝的記憶を想起させる課題ページを掲載するための枠です。

公開URL例：
./autobiographical-memory/

資料 研究者向け

研究資料・説明文書

教示スクリプト，同意説明文書，健康確認シート，RPE提示カードなどの資料を整理して掲載するための枠です。

公開URL例：

推奨フォルダ構成

GitHub Pages で管理しやすいように，プログラムごとにフォルダを分ける構成をおすすめします。 

sotsu-ron/
├─ index.html
├─ panas_pre_post/
│  └─ index.html
├─ autobiographical-memory/
│  └─ index.html
├─ documents/
│  ├─ consent.pdf
│  ├─ health-check.pdf
│  └─ rpe-card.pdf
└─ README.md

GitHub Pages の設定方法

次の手順で，GitHub上に公開ページを作成できます。

  1. 1
    リポジトリ sotsu-ron にファイルを置く

    トップ階層にこの index.html を置き，PANASプログラムは panas_pre_post/index.html に配置します。

  2. 2
    Settings で GitHub Pages を有効化する

    Settings → Pages を開き，公開元を Deploy from a branch，ブランチを main，フォルダを /(root) に設定します。

  3. 3
    公開URLを確認する

    トップページは https://USERNAME.github.io/sotsu-ron/，PANASページは https://USERNAME.github.io/sotsu-ron/panas_pre_post/ になります。

このページで編集する箇所

実際に運用するときは，次の箇所を研究内容に合わせて編集してください。

USERNAME の置き換え

https://USERNAME.github.io/... の USERNAME を，ご自身の GitHub ユーザー名に置き換えてください。

各プログラムへのリンク

実際のフォルダ名やファイル名に合わせてリンク先を調整してください。PANASは panas_pre_post に対応済みです。

資料公開の範囲

参加者向けページと，研究者向け内部資料が混在しないように整理します。
